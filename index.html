YOUR PREFERENCES

Settings & sync.

Choose how UniPlanner stores and protects your work.

Data & backup

Your planner starts fresh. Data is stored locally in this browser by default.

Notifications are off by default. A past-due task is never repeatedly alerted. Browser permission is requested only if you turn reminders on.

Cross-device sync

GitHub Pages is static hosting, so shared sync needs a backend. This app supports a Supabase project when you configure its public URL and anon key below. Never paste a service-role key here.

Cloud not configured

Before use: create the database table and row-level security policies using supabase-schema.sql in the project. Sync is not active until configured.
